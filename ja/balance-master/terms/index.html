Balance Master 利用規約

第1条（目的）

本規約は、IdeaBank（以下「開発者」）が提供するモバイルゲーム「Balance Master」（以下「本ゲーム」）の利用に関して、開発者と利用者との間の権利、義務および責任事項を定めることを目的とします。

第2条（用語の定義）

  1. 「本ゲーム」とは、開発者が開発および運営するモバイルゲーム「Balance Master」をいいます。
  2. 「本サービス」とは、本ゲームを通じて提供されるゲームコンテンツ、広告、アプリ内購入など開発者が提供する機能の全体をいいます。
  3. 「利用者」とは、本規約に従って本ゲームをインストールし利用する者をいいます。
  4. 「ゲームデータ」とは、ゲームの進行過程で生成され利用者の端末に保存される進行状況、ゲーム内通貨、アイテム、記録、設定などの一切のデータをいいます。
  5. 「アプリ内購入」とは、利用者がGoogle PlayまたはApp Storeを通じてゲーム内の有料商品を購入することをいいます。
  6. 「広告削除」とは、アプリ内購入によりゲーム内のインタースティシャル広告の表示を停止させる商品をいいます。

第3条（規約の効力および変更）

  1. 本規約は、本ゲームをインストールして利用するすべての利用者に対して効力を生じます。
  2. 開発者は、関連法令に違反しない範囲で本規約を改定することができます。
  3. 規約を改定する場合、開発者は改定内容および施行日を明示し、施行日の7日前までに本規約を掲載するウェブページまたはストアのアプリ詳細ページを通じて告知します。
  4. 利用者が改定規約に同意しない場合、本ゲームの利用を中止し本ゲームを削除することにより利用契約を解除できます。
  5. 改定規約の施行日以降も利用者が本ゲームを継続して利用する場合、改定規約に同意したものとみなします。

第4条（サービスの提供）

  1. 開発者は、利用者にゲームコンテンツの利用を無料で提供します。本ゲームは会員登録やログインなしで利用できます。
  2. 本ゲームのプレイはネットワークに接続していない状態でも可能です。ただし、広告の表示およびアプリ内購入はネットワークに接続された状態でのみ利用できます。
  3. 開発者はゲーム内にインタースティシャル広告およびリワード広告を表示することができ、これは無料で提供されるサービスの運営原資となります。
  4. 開発者はゲーム内で広告削除、ゴールドパッケージなどの有料商品を販売することができます。

第5条（サービスの変更および中断）

  1. 開発者は運営上または技術上の必要に応じて、ゲームのコンテンツ、レベル構成、ゲーム内数値および商品構成を変更することができます。ゲームの利用に重大な影響を及ぼす変更事項は事前に告知します。
  2. 開発者は、広告やアプリ内購入など外部サービスと連携した機能に障害が発生した場合、当該機能の全部または一部を一時的に中断することができます。
  3. 開発者は運営上、技術上その他の事由によりサービスを終了することができます。この場合、終了の事由および終了日を明示し、終了日の30日前までに本規約を掲載するウェブページまたはストアのアプリ詳細ページを通じて告知します。
  4. サービスが終了した後も、すでに端末にインストールされた本ゲームのオフラインプレイは継続して可能な場合がありますが、開発者はこれを保証しません。

第6条（ゲームデータの保存）

  1. ゲームデータは利用者の端末内にのみ保存されます。本ゲームはクラウド保存、アカウント連携、端末間のデータ移行の機能を提供しません。
  2. 利用者がゲーム内の［設定］メニューからデータの初期化を実行した場合、本ゲームを削除した場合、端末を初期化した場合、または他の端末に機種変更した場合、ゲームデータは削除され復元できません。
  3. 端末の故障、紛失、OSの再インストールなどによりゲームデータが失われた場合も、開発者はこれを復元できません。開発者はゲームデータを保管していないため、確認することもできません。
  4. 利用者は、ゲームデータが端末内にのみ保存されることを理解したうえで本ゲームを利用するものとします。

第7条（アプリ内購入）

  1. 利用者はGoogle PlayまたはApp Storeを通じてゲーム内の有料商品を購入できます。
  2. 有料商品の価格はストアに表示された金額に従い、為替レート、税金およびストアのポリシーにより国ごとに異なる場合があります。
  3. 決済はGoogleまたはAppleが処理し、開発者は利用者の決済手段情報を収集または保管しません。
  4. 購入した商品は、購入が行われた端末およびストアアカウントに帰属します。本ゲームはアカウント連携を提供しないため、ゲームを削除して再インストールした場合、ストアが提供する購入復元機能が対応する範囲でのみ商品が復元されます。
  5. ゴールドなどの消費型商品は使用と同時に消費され、復元の対象となりません。

第8条（返金）

  1. アプリ内購入の返金は、Google PlayまたはApp Storeの返金ポリシーおよび各国の消費者保護法令に従います。決済および返金の主体は当該ストアです。
  2. 利用者が返金を希望する場合は、購入したストアの返金手続きを通じて申請する必要があります。
  3. 開発者はストアの返金判断を代行または覆すことはできません。ただし、ゲームの不具合により商品が付与されなかった場合など開発者に責任がある事案については、第13条のメールアドレスにお問い合わせいただければ確認のうえ対応します。
  4. 返金が行われた場合、開発者は当該購入により付与されたゲーム内通貨、アイテムおよび特典を回収することができます。

第9条（広告および広告削除商品）

  1. 本ゲームは無料で提供され、その対価としてインタースティシャル広告およびリワード広告を表示します。
  2. リワード広告は利用者が自ら視聴を選択した場合にのみ表示され、視聴を完了するとゲーム内の報酬が付与されます。
  3. 広告削除商品を購入すると、インタースティシャル広告は表示されなくなります。リワード広告に対応する報酬は、広告を視聴しなくても即時に付与され、報酬の回数制限などの条件は同様に適用されます。
  4. 広告削除の効力は、購入が行われたストアアカウントおよび端末に限定されます。本ゲームはアカウント連携を提供しないため、他の端末へ自動的に引き継がれることはありません。
  5. 広告の内容は広告ネットワークが決定するものであり、開発者は個々の広告の内容に関与しません。

第10条（利用者の義務および禁止行為）

利用者は本サービスの利用にあたり、次の各号の行為を行ってはなりません。

  1. ゲームデータまたはアプリケーションを改造し、または改造されたクライアントを使用する行為
  2. メモリ改変ツール、マクロ、自動化ツールなどを利用して本ゲームを不正に利用する行為
  3. 決済システムを迂回して有料商品を取得し、または不正な方法で広告報酬を取得する行為
  4. 広告を自動的に視聴し、または不正な方法で広告収益を発生させる行為
  5. 本ゲームのコンテンツを無断で複製、配布、改変し、または商業的に利用する行為
  6. その他関連法令に違反し、または開発者の正当なサービス運営を妨害する行為

第11条（ゲームデータの帰属）

  2. 利用者はゲームデータをゲーム外部で他人に譲渡、貸与、販売し、または担保に供することはできません。
  3. 第10条に違反した事実が確認された場合、開発者は不正に取得されたゲームデータを回収することができます。
